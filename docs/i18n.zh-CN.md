# i18n — 国际化指南

状态:**接线完成**(提交 `9b2839b`、`34cead3`、`8c8d303`、`fa85d78`、`5ddb05b`)。

编辑器组件全部与语言解耦:所有用户可见的界面文案(工具提示、右键菜单、占位符、确认框、降级 UI)都经由 i18n 层解析。英文为源语言,简体中文随包内置。

## 快速开始

```tsx
import { JdmConfigProvider } from '@republicroad/seal-editor';

// 内置 zh-CN;其他语言可通过部分 message 映射补充
<JdmConfigProvider locale='zh-CN'>
  <DecisionGraph ... />
</JdmConfigProvider>

// 宿主为未内置语言提供覆盖词条
<JdmConfigProvider
  locale='de'
  messages={{ 'dt.toolbar.export': 'Excel exportieren', 'common.remove': 'Entfernen' }}
>
  <DecisionTable ... />
</JdmConfigProvider>
```

不传 Provider 时库默认渲染英文——零配置即是合法默认,编辑器运行不依赖 Provider。

## 架构

| 模块 | 职责 |
|---|---|
| `theming/i18n.tsx` | `I18nProvider`(由 `JdmConfigProvider` 注入)、`useT()` Hook、`createT(locale)` 工厂 |
| `theming/messages/en.ts` | 源语言词条表(189 个扁平 `'ns.key'` 键),导出 `TranslationKey` 类型 |
| `theming/messages/zh-CN.ts` | 内置中文词条,键位齐平由测试锁定 |
| `theming/i18n-types.ts` | `{{param}}` 插值辅助 |

- **回退链**:宿主 `messages` 覆盖 → `locale` 词条表 → `en` → 原始键。
  缺键不抛错:先渲染英文,再渲染键名本身。
- **键类型化**:`useT()` 接受 `TranslationKey | string`,库内调用享有键名自动补全,
  宿主也可传入任意覆盖键。
- **插值**:`'{{count}} rows'` — `t('key', { count: 3 })`。

## 覆盖范围

所有界面文案均已接线:决策表(工具栏/菜单/字段编辑器/Excel 对话框)、决策图
(面板/标签页/节点/模拟器/Schema 标签页)、表达式与函数编辑器、
expression-builder、自定义函数表格(`cf.*`),以及 SafeBoundary 降级 UI
(经由内部函数组件渲染——class 边界无法调用 Hook)。

当前无已知限制。规格 `renderNode` 回调在组件渲染树内执行(其本就调用
zustand hooks),因此直接消费 `useT()` 并随 locale 响应。

## 测试

- `theming/__tests__/i18n.test.tsx` — Provider 解析、覆盖优先级、回退链、插值、
  en/zh 键位齐平。
- 词条齐平受强制约束:`en.ts` 新增键而 `zh-CN.ts` 缺失时 CI 失败。

## 新增词条

1. 在 `theming/messages/en.ts` 添加 `'ns.key': 'English'`。
2. 在 `zh-CN.ts` 添加对应翻译(齐平测试会拦截遗漏)。
3. 组件内通过 `const t = useT(); … t('ns.key')` 消费。

不要把用户数据拼进键名;键是标识符,参数才是值。
