## 总表

| 求值上下文 | 裸 `$` | `$root` | `$nodes.<名>.<字段>` | 裸标识符 | 引用失败行为 |
| --- | --- | --- | --- | --- | --- |
| 表达式节点行值 | 行输出累积域：`$.<rowKey>` 引先行行 | 节点输入根 | 先行节点输出 | 输入字段 | **静默丢行** |
| 决策表输入单元 · unary（field 列） | 列值（unary 左操作数） | — | — | —（操作数隐式） | 无命中 |
| 决策表单元 · 全表达式 | 未绑定（**不**指输入根） | 节点输入根 | 先行节点输出 | 输入字段 | 无命中/缺键 |
| 独立求值 `evaluateExpression(Sync/Async)` | 未绑定 | 上下文根 | — | 上下文顶层键 | 返回 null |
| 函数节点 functionNode | JS 代码节点：`$` 不适用，input 即 handler 参数 | | | | |
| zen-udf 自定义节点 kwargs | 不接通 `$`（dollar-scope 裁定档） | | | | |

一句话口径：**决策图节点内 `$` 是"节点自己"的作用域（表达式节点=行输出域，决策表全表达式单元=未绑定），输入永远裸名/`$root`；独立求值里 `$` 不存在；`$root`/`$nodes` 在节点与独立求值里普遍可用。**

## 实证记录

实测脚本六轮，关键用例（输入 `{a:1, b:2}` / `{u:{a:1}}` / `{v:1}`）：

| # | 用例 | 结果 |
| --- | --- | --- |
| 1 | 表达式行 `g = $.c`（c 为先行行） | `g: 3` ✓ |
| 2 | 表达式行 `e = $.a`（a 为输入字段，非行键） | 行 `e` **静默丢弃**（输出无 e 键，不报错） |
| 3 | 表达式行 `f = a + b`（裸名引输入） | `f: 3` ✓ |
| 4 | 表达式行 `f = $root.a` | `f: 1` ✓（`$root` = 节点输入根） |
| 5 | 表达式行 `d = $nodes.expression1.c * 2` | `d: 6` ✓（跨节点引用） |
| 6 | inputField=user，行 `r = a` | `r: 1` ✓（裸名对映射后输入求值） |
| 7 | 表达式行 `x = v`，先行行 `v = 99`，输入 `{v:1}` | `x: 1`——**裸名指输入，行键不遮蔽裸名**；输出 `v:99`（行输出覆盖同名输入键） |
| 8 | 决策表全表达式单元 `$.a == 1` | 无命中——`$` 不指输入根 |
| 9 | 决策表全表达式单元 `$root.a == 1` / `$nodes.x.c == 3` | 命中 ✓ |
| 10 | field 列 + unary 单元 `== 1` / `$ == 1` | 均命中——unary 里 `$` = 列值 |
| 11 | field 列 `u.a` + unary `== 1` | 命中 ✓（field 支持嵌套路径） |
| 12 | 输出单元 `$root` | 输出整根 `{r:{a:1}}` ✓ |
| 13 | 独立求值 `$.a` | null（静默） |
| 14 | 独立求值 `$root` / `$root.a` | `{a:1}` / `1` ✓ |

## 格式边界（附带实证）

- 原生引擎仅支持**平铺 jdm 格式**（`inputs`/`outputs`/`rules` 按列 id 键控）；GoRules documents 的
  `columns.inputs[].expression` 变体直接解析失败（`missing field 'inputs'`）。
- **hitPolicy 严格双值**：决策表与 switch 均只接受 `first`（单对象）/ `collect`（命中规则输出数组）；
  `standard` 报 `unknown variant`（2026-10-10 实测，修正 GoRules cloud 文档口径的误植）。
- 决策表列双形态并存：`field` 列（字段路径 + unary 单元）与无 field 列（全表达式单元）可各自独立工作。
- 表达式行必须带 `id`（缺 id 解析失败：`missing field 'id'`）。

## 编辑器校验启示

1. **静默丢行**（用例 2）：行引用写错不报错——检查器应对"`$.<非行键>` 且该名恰为输入字段"给出"改为裸名"修复提示。
2. **同名三义**（用例 7）：行键与输入字段同名时，裸名视输入、输出被行覆盖——漂移带宜作 hazard 提示。
3. **决策表 `$` 误用**（用例 8）：从表达式节点迁来的作者易写 `$.field`——决策表全表达式单元应提示 `$root` 或裸名。

## 历史口径勘误

此前会话记录"evaluateExpression `$` 根未绑定"——实测精确化为：裸 `$` 未绑定（用例 13），
**`$root` 绑定为上下文根**（用例 14）。
