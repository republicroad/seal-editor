# Ubuntu 26 迁移窗口——CI runner 解钉与预算重测计划

- 日期：2026-10-02 立项
- 状态：**待开启 · 暂不开启**（宿主指示 2026-10-02——先写入文档占位，开启需明确口令）
- 上位：批次 α/β 规划（1.18.0 发版批后的时限项）；量级 ~0.5-1 天

## 背景

GitHub 自 **2026-10-19** 起将 `ubuntu-latest` 迁移至 Ubuntu 26。本仓 CI runner
已显式钉 `ubuntu-24.04`（validate.yaml）——迁移发生时本仓**不会坏**，但钉子
会老化：24.04 镜像终将停止维护，且与 `latest` 的行为差异随时间扩大。

体积/行为基线在 24.04 工具链下校准（scripts/size-budgets.json：index raw
830000 / style raw 160000——历次校准均在 24.04 runner 实测），26 的工具链
（Node/glibc 版本差异）可能改变构建产物与测试行为，需独立窗口重测。

## 为什么是「窗口」而非立即迁移

- 体积预算基线的可信度建立在 24.04 实测上——26 下重测会**重置基线**，
  应在功能批次收口的稳定点做，避免与功能变更叠加归因；
- 迁移本身无产品价值，纯基建——排期让位于主线。

## 开启条件（满足其一即可入窗口）

1. 24.04 镜像出现停止维护/构建异常信号；
2. 主线功能批次收口后的版本窗口（如 1.19.0 发版批之后）；
3. 宿主明确指示。

## 内容清单（开启时执行）

| # | 项 | 验收 |
| --- | --- | --- |
| 1 | validate.yaml / publish.yaml runner 解钉（`ubuntu-24.04` → `ubuntu-latest`） | 两 workflow 各一处 |
| 2 | 解钉后全量 CI 观察一轮 | 重点：size（index.js/style.css gzip）、Storybook 交互套件、消费冒烟 |
| 3 | 不达标项校准 | size-budgets.json 按新工具链实测重校（历次校准先例：820000→826000→830000 等）；时序 flake 单独定性 |
| 4 | 必要时回退 | revert 解钉提交即回 24.04，无数据/格式迁移成本 |

## 回退与风险

- 回退 = revert 单提交，零迁移成本（无数据、无格式、无依赖变更）；
- 风险仅两条：① 新工具链下构建产物字节级变化 → 预算重校；② 测试时序行为
  变化 → flake 定性（历次 flake 记录在案可对照）。

## 关联

- runner 钉注：validate.yaml L15（首提 1.17.0 批次二可靠性批）
- 体积预算校准史：scripts/size-budgets.json + 各批次提交记录
- 同类先例：本仓无（首次 runner 迁移决策）
